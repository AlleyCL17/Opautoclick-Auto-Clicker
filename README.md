# Opautoclick Auto Clicker 1.0
  
OP Auto Clicker is a free, portable auto clicker for Windows. You choose how
often it clicks, which mouse button it uses, and a hotkey to start and stop it.
There is nothing to install: extract the ZIP and run the program.

Website: https://opautoclick.com/

## Features

- Adjustable click interval (hours, minutes, seconds and milliseconds)
- Left, right and middle mouse buttons, with single or double clicks
- Repeat a set number of clicks or click until you stop it
- Click at the current cursor position or at fixed X and Y coordinates
- Custom start/stop hotkey (default: F6)
- Record and playback of click sequences
- Portable: runs from a single folder, no installation required

## Requirements

- Windows 7, 8, 10 or 11
- Download size: 18.2 MB (ZIP file)

## How to use

1. Download the ZIP file from the Files section.
2. Right-click the ZIP and choose **Extract All**.
3. Run the program from the extracted folder.
4. Set the click interval, mouse button and click type.
5. Choose a hotkey or keep the default (F6).
6. Move the cursor to the target spot, press the hotkey to start, and press
   it again to stop.

Tip: if clicks don't register in a particular app, right-click the program
and choose **Run as administrator**.

## Verify your download

Before you run the file, check that it matches the SHA-256 hash below.

```
SHA-256: PASTE-YOUR-HASH-HERE
```

On Windows, run this in PowerShell:

```
Get-FileHash .\YOUR-FILE-NAME.zip -Algorithm SHA256
```

Windows SmartScreen or your antivirus may show a warning for software that is
not widely downloaded. Compare the hash, scan the file with Microsoft Defender
or another scanner, and only run it if you are comfortable.
